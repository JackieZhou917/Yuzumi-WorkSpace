# 什么是弹性布局
Flexible Box, css 中一种渐变的，响应式的布局方案

1. 弹性容器会默认将子容器在X轴 (主轴) 排列

2. flex-grow: 1; 控制所有的子容器在父容器空间有盈余的情况下沿主轴方向按比例扩大
3. flex-shrink: 1; 控制所有的子容器在父容器空间不足的情况下沿主轴方向按比例缩小
4. flex-basis: 200px; 控制所有的子容器的默认宽度
5. flex: 0 0 200px; 第一个参数 flex-grow 第二个参数 flex-shrink 第三个参数 flex-basis

6. flex-wrap: wrap; 父容器空间不足允许换行


# 三栏布局
  - 通过弹性布局设置左右两边容器固定宽度，中间主体内容 flex: 1; 为了考虑主体内容先加载，可以调整html顺序，然后用 order:-1; 控制布局先后
