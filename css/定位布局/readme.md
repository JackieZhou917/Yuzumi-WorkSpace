# 定位布局
开发页面的时候，常常需要确定将某一个容器展示在页面的某个地方，如何控制它的位置。

1. position: relative; 相对定位: 参考自己本身的文档流的位置来定位，原有的文档流位置还存在。相对定位不会导致脱离文档流。
2. position: absolute; 绝对定位: 找自己的外层拥有定位属性的父容器的当前显示位置来做参考，如果找不到，会以 body 为标准。绝对定位会导致容器脱离文档流。
3. position: fixed; 固定定位: 以浏览器可视区域为参考标准来定位。
4. position: sticky; 黏性定位: 以浏览器可视区域为参考标准来定位。

- 层级: z-index
  1. 下面的标签比上面的标签优先级更高，后面的会盖住前面的。层级z-index要生效，必须要配合定位属性position
  2. 层级只能在兄弟元素之间相比较，自己的子元素与兄弟元素的层级无法相比较

- 层级：z-index
  1. 元素重叠时，默认情况下后面的元素通常会覆盖前面的元素。
  2. z-index 用于设置元素的层叠顺序，数值越大通常越靠上。
  3. z-index 常与 position 定位属性配合使用，如position: relative;；flex/grid 子元素属于例外，即使没有 position，z-index 也可以生效。
  4. z-index 的比较受到层叠上下文限制。不同父级层叠上下文中的子元素，不能只比较自身 z-index，需要先看父级所在的层级。

# 文档流
页面布局默认是从上往下，从左往右的排列，呈现一种流式的排列

1. 块级元素：默认占据父容器的一整行，可以设置宽高
2. 行内块级：可以同一行排列，也可以设置宽高
3. 行内元素：可以同一行排列，不可以设置宽高
