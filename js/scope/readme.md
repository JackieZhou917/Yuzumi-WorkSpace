# JS引擎
1. 浏览器: V8引擎
2. Node.js: V8引擎(有微小区别)

# JS的执行
1. V8会读取代码，并不会第一时间执行，而是要先编译（梳理）
2. 分词: 将代码拆分成一个一个的词法单元
3. 解析/语法分析: 将词法单元组织成一个语法树 AST (抽象语法树 Abstract Syntax Tree)
4. 执行: 根据 AST 生成代码并执行 

# 作用域
1. 全局作用域
2. 函数作用域
3. 块级作用域

在 V8 的执行过程中，查找一个变量时会先在当前作用域中查找，如果找不到，就会去外层作用域中查找，直到找到全局作用域。如果还是找不到，就会报错。

# let, const
1. let/const + {} 会形成块级作用域
2. let/const 不会带来声明提升
3. let/const 会在块级作用域内带来暂时性死区
3. const声明的是常量，不能被重新赋值
