# 对象
- 万物皆对象

1. 原始类型: string, number, boolean, undefined, null, bigint ,symbol
2. 引用类型: object, array, function

- 创建对象的方式
1. 字面量: {}   (本质V8还是用new Object)
2. 构造函数: new Object()
3. new 一个构造函数

- 函数有二义性：可以普通调用，也可以 new 调用；而且被 new 调用的话，一定会有一个新对象

- new 的工作原理
  1. new 会往函数内凭空创建一个 this 对象
  2. 执行函数中的代码
  3. 让这个对象实例的原型 等于 函数的原型 this.__proto__ = XXX.prototype
  4. return 这个 this 对象

# 包装类（包装对象）：当基本数据类型需要访问属性或调用方法时，JavaScript 会临时将其转换为对应的包装对象，使其能够访问包装对象原型上的属性和方法；操作结束后，这个临时包装对象不再保留，原来的值仍然是基本数据类型。
- 原始类型是不能添加属性和方法的
- V8 在对象中查找属性，如果找不到，一定会去它的原型上找

1. 当用户创建一个字面量，V 8 会默认执行成 new XXX()
2. 因为原始类型不能增加属性和方法，所以，V8在 new 出这个实例对象后，立即做一个拆箱操作
3. str.length length 是 String 函数原型上的属性，并不是给字符串增加的属性

# 对象
- “万物皆对象”并不严谨：JS 中基本类型不是对象，但很多功能都围绕对象和原型系统展开；基本类型在访问属性或方法时也可以临时表现得像对象

1. 原始类型: string, number, boolean, undefined, null, bigint, symbol
2. 引用类型: object
   - 普通对象
   - array
   - function
   - Date、Map、Set 等

- 创建对象的方式
1. 字面量: {}  (本质V8还是用new Object)
2. 构造函数: new Object()
3. new 自定义构造函数

- 函数具有二义性
1. 普通调用: 执行函数代码
2. new 调用: 作为构造函数使用，并创建一个新的实例对象。但并非所有函数都能被 new，例如箭头函数不能作为构造函数

- new 的工作原理
1. 创建一个新的对象
2. 让新对象的原型指向构造函数的 prototype: this.__proto__ = XXX.prototype
3. 让构造函数中的 this 指向这个新对象
4. 执行构造函数中的代码
5. 判断构造函数的返回值
   ├─ 没有显式 return      → 返回新创建的 this 对象
   ├─ return 基本类型      → 忽略这个基本类型，返回新创建的 this 对象
   └─ return 对象         → 直接返回这个对象，不再返回 new 创建的 this 对象
# 原型与原型链
- 每个实例对象都可以通过原型关系关联到构造函数的 prototype 对象

- 同一个构造函数创建的实例，默认共享同一个 prototype 对象

- prototype 适合存放多个实例需要共享的属性和方法

- 实例自身的数据可以存放在实例对象自身，不会因为共享 prototype 而发生冲突

- 属性查找规则
1. 先查找对象自身的属性
2. 自身没有，则沿着原型链向上查找
3. 一直查找到 Object.prototype
4. 最终到 null，仍然没有找到则返回 undefined

- 如果实例自身和原型中存在同名属性，会优先访问实例自身的属性，这种现象可以理解为“属性遮蔽”

- 对象拥有某个属性，不代表这个属性一定可以修改；属性是否可修改由属性描述符中的 writable 等特性决定

- String 实例自身拥有 length 属性，不同 String 实例的 length 可以不同；该属性是不可写的，因此不能直接修改

# String 基本类型与 String 对象
- 字符串字面量属于基本类型，例如 'abc' 的类型是 string

- new String() 创建的是真正的 String 对象，类型是 object

- 字符串字面量和 String 对象表示的内容可以相同，但两者的数据类型不同

- 实际开发中通常使用字符串字面量，不推荐使用 new String() 创建字符串对象

# 包装类（包装对象）
- 当基本数据类型需要访问属性或调用方法时，JavaScript 会临时将其对象化，使其能够使用对应包装对象提供的属性和方法

- 操作结束后，这个临时包装对象不再保留，原来的值仍然是基本数据类型

- “临时创建一个 new String() / new Number() 对象”可以作为帮助理解包装机制的模型，但不代表 JS 引擎内部一定真正执行了 new

- 常见对应关系
1. string → String
2. number → Number
3. boolean → Boolean
4. symbol → Symbol
5. bigint → BigInt

- undefined 和 null 没有对应的包装对象，不能直接访问属性和方法

- Symbol 和 BigInt 可以进行对象化，但不能使用 new Symbol() 或 new BigInt()

- 原始类型本身不能真正保存自定义属性

- 给基本类型设置自定义属性时，这些属性不会长期保存在基本值上；之后再次访问时无法获取之前设置的属性
