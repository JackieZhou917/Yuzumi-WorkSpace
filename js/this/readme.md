# 为什么要有this
- this 是 js 中的一个关键字，它提供了一种更优雅的方式隐式的传递一个对象的引用，可以让代码更简洁易于复用

# this 可以出现在哪
1. 全局  this === window
2. 函数体内 

- this 用在不同的地方，代指的内容是不一样的

# this 的绑定规则  先分析 this 是谁的，在来分析this指向谁
1. 默认绑定  ---  当函数独立调用("foo()")时，函数中的 this 指向 window
2. 隐式绑定  ---  当一个函数被一个上下文对象所拥有，并被该对象调用，那么函数中的 this 指向该对象
3. 隐式丢失  ---  当一个函数被多层对象调用，函数的 this 指向最近的那个对象
4. 显示绑定  ---  
        fn.call(obj, x, y)
        fn.apply(obj,[x, y])

        fn.bind(CRQ, x, y)()

5. new绑定  ---  new 的原理会导致函数的 this 指向实例对象

# 箭头函数
- 箭头函数没有 this 这个概念，写在箭头函数里的 this, 也是它外层那个非箭头函数的 this
- 箭头函数不能被 new 调用，因为没有 this
