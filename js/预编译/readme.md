 # 预编译
 编译发生在代码执行之前

 # 函数体内的预编译
 1. 创建一个执行上下文 AO: {}
 2. 找形参和变量声明，将形参和变量名作为属性名，添加到 AO 中，值为 undefined
 3. 将形参和实参统一，将实参值赋给形参
 4. 在函数体内找函数声明，将函数名作为 AO 中的属性名，函数体作为属性值

 # 全局的预编译
 1. 创建一个全局上下文 GO: {}
 2. 找全局变量声明，将全局变量名作为属性名，添加到 GO 中，值为 undefined
 3. 找全局函数声明，将全局函数名作为 GO 的属性名，函数体作为属性值
