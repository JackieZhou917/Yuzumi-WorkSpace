# 异步
1. 能按顺序从上往下依次执行  (同步执行)
2. 在执行的过程中，如果碰到一个耗时的任务，就分精力出来执行另一个任务  (异步执行)

- js 默认是单线程执行的
  1. 线程: CPU 执行指令所需要的时间
  2. 进程: CPU 接收到一个指令，到加载完上下文所需要的时间
  3. 进程负责“提供运行环境和资源”，线程负责“真正执行代码”

举例: 
- 进程 = 一家独立的工厂：有自己的厂房、仓库、设备（独立资源），工厂之间互不干扰。
- 线程 = 工厂里的工人：多个工人可以在同一个工厂里共享厂房、工具，同时分工干活；工人之间沟通成本低，切换工作也快。

启动 node 来运行 js，这可以称之为一个进程，但是 v8 默认只会开启一个线程来运行代码，所以遇到耗时的任务，会现将它挂起，先去执行不耗时的任务

# 回调
当 B 函数需要依赖异步 A 的结果，我们将 B 函数的调用放在 A 里面

回调地狱：当程序繁重，有大量异步嵌套时，排查问题的难度大，可读性差
