# LLM的工作
输出，文本，图片或者其他多模态的内容，这些内容仅仅只是LLM在训练过程中掌握的内容，一旦用户的需求超出了训练的数据，或者实时性很高，LLM就无法处理，会胡言乱语 (幻觉)

# Tools 工具函数
用户请求 -->  LLM --> 调用工具函数 --> LLM --> 用户

- 调用工具函数
1. LLM 要返回它想要调用的tools的名字
2. 我们在程序中判断当获取到LLM返回的内容时并拿到它想要调用的tools的名字，就触发该tools
3. 得到tools的结果继续传给LLM
4. 让LLM将tools的结果整理并返回给用户
