# 流式输出
流式输出是指在LLM运行过程中，将输出分块地发送给客户端，而不是等待整个输出完成后再发送。
 1. 前端解码流式资源
 2. SSE （server-sent events）, 正常情况下无法在前端直接使用，SSE只支持 HTTP GET 方式，不能发送自定义的Header，而多数情况下我们在调用LLM都是需要配置请求头的，而且必须使用POST
  - BFF层来处理（node）
