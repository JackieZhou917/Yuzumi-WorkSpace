# JS 弱类型动态语言
1. 弱类型  --  v8 在执行时会判断变量的类型，根据类型进行操作，我们在书写代码时不需要指明变量的类型

2. 动态语言  --  赋值操作可以重新改变变量的类型

# 强类型静态语言
1. 强类型  --  编译时会检查变量的类型，根据类型进行操作，我们在书写代码时需要指明变量的类型
2. 静态语言  --  赋值操作不能重新改变变量的类型


# typescript
是 js 的超集，添加了类型检查和编译时错误检查等功能，ts不是一门新语言，浏览器也无法执行ts，需要通过ts编译器编译成js才能执行
