# hooks
  1. useState()   当接收的默认值是函数体时，函数体内部不支持异步
  2. useEffect()  -- 副作用函数
    - 不传第二个参数依赖数组时，即没有依赖数组时，副作用函数会在组件初次挂载和每次渲染时执行
    - 传入第二个参数依赖数组时，且依赖数组为 [] 时，副作用函数只会在组件初次挂载时执行，后续每次渲染不会执行
    - 传入第二个参数依赖数组时，且依赖数组内有响应式变量时，副作用函数会在组件初次挂载以及依赖数组中的变量发生变化时执行
    - 可以在副作用函数中返回一个函数，该函数会在组件卸载时执行
  3. useRef()
    - 可以用来获取 DOM 结构
    - 也可以用来缓存住一个值
  4. useContext()
    - 顶层组件创建上下文对象并 provider 出一个值，后代组件可以引入该上下文对象并借助 useContext() 读取顶层组件 provider 出来的那个值
    - 顶层组件 provider 出来用useState定义的一个值和一个修改该值的函数，后代组件可以引入该函数去修改顶层组件中的变量，从而导致其他的后代组件中的更新

# 组件传值
  1. 父向子传值: 父组件通过属性传递，子组件通过 props 接收，且该属性props是只读的，不可修改
  2. 子向父传值: 父组件创建一个函数传给子组件，子组件调用该函数并将要传递的数据作为实参传入函数中，父组件则可以直接在函数中使用该数据
