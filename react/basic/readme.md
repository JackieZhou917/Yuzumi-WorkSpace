# 传统开发
1. 多页应用，每个页面都是一个 html 文件
2. 没有可复用的模块


# react
1. 单页应用，只有一个html文件
2. 组件化开发，将每个页面的结构写成一个组件 (代码块)，将某一个组件添加到html文件中

- 怎么写代码块？
    jsx 语法，就是 react 中提供的一种模板语法，我们创建 jsx 文件写的代码都是最后要被 react 自带的解析器变成 js 供浏览器执行。

# vite + react
  1. vite是一个构建工具，用于构建初始项目，打包项目，提供了一些配置项，让我们可以在项目中配置一些便捷的写法
  2. react 提供了 jsx 语法，让我们可以将页面的某一块结构写成一个组件，并将组件编译成 js 供浏览器执行
